      What will happen

      1. Revalidate the phone, selected extension, location, and current assignments.
      2. Save the supported line association in Webex Calling.
      3. Trigger Phonism Sync so the phone receives the updated Webex configuration.
      4. Automatically reboot the phone through Phonism TR-069 so the temporary line is applied to the handset.
      5. Recheck Line 2 state and record the result in Change History.
      6. At the selected expiration time (maximum 12 hours), restore the permanent Webex baseline and force another Phonism Sync.
      7. If Webex changed outside this platform during the temporary lease, preserve the newer external state instead of overwriting it.
      8. Preserve existing Webex BLF / Line Monitoring entries. This workflow does not modify monitoring settings or monitored keys.
      9. If verification still needs attention, allow Reboot & Reverify again.

      Save & Sync automatically queues a phone reboot after the Webex change and Phonism Sync.
