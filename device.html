      Verification & Admins

      Controls apply to the Device & Extension Manager only.

      Email verification

      Require a six-digit email code before an operator can Review, Save & Sync, or Reboot & Reverify.

      Verified session duration

      The six-digit code still expires after 10 minutes. This controls how long a successful verification remains trusted on that browser.

      Default is 24 hours. Per-user overrides can be set from 1 to 720 hours. Changes apply the next time that user verifies; an existing verified session keeps its current expiration.
